# Prajwal Mhetre — Engineering Portfolio

A modern portfolio spanning semiconductor design, embedded systems, AI/ML, backend engineering and cloud-native software.

## Portfolio sections
- Profile and education
- Semiconductor & embedded engineering focus
- Software and intelligent systems focus
- Selected public GitHub repositories
- Searchable project roadmap: 50 semiconductor + 50 software project concepts
- Music & focus section
- Contact links

## Project-status transparency
The 100-entry project library is a curated roadmap/catalogue. It does **not** claim that all 100 projects are completed. Selected repository cards link to existing public repositories so visitors can inspect the actual work.

## Stack
- Next.js 16 / React 19 / TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide icons
- Vercel deployment

## Local development
```bash
npm install
npm run dev
```

## Validation
```bash
npm run lint
npm run build
```

## Profile image
The hero portrait is served from `public/profile.jpg`.

## Deployment
The repository is connected to Vercel for Git-based deployments. Review deployment status and build logs after each push before promoting changes to production.
